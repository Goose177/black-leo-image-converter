ပုံထည့်ရန် နှိပ်ပါ သို့မဟုတ် ဆွဲထည့်ပါ

အများဆုံး ဖိုင်အရွယ်အစား: 5MB

ပြောင်းလဲရေး ထိန်းချုပ်မှုများ

JPEG အရည်အသွေးကို ဝဘ်အတွက် အသင့်တော်ဆုံးဖြစ်စေရန် 75% ဖြင့် သတ်မှတ်ထားပါသည်။

ပုံအချက်အလက်များကို Base64 စာသား Code အဖြစ် ပြောင်းလဲပေးပါမည်။ ဒေတာထည့်သွင်းရန်အတွက်သာ အသုံးပြုနိုင်ပါသည်။

ပုံ၏ Binary အချက်အလက်များကို Base64 Stream အဖြစ်သာ ထုတ်ယူပြီး ဖိုင်တစ်ခုအနေဖြင့် သိမ်းဆည်းပေးပါမည်။
